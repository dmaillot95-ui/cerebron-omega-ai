# CÉRÉBRON ΑΩ — AGORA Weight Artifact Pipeline
Authority: AFAH
Status: DESIGN RULE

## Rule
Large neural artifacts generated by an AGORA task (full weights, checkpoints, LoRA/adapters) MUST NOT be committed to GitHub.

GitHub is the control plane:
- task/run identity;
- producing colony/SAPHEA;
- base model + pinned revision;
- training recipe/config when non-sensitive;
- license/provenance status;
- benchmark/audit/Red-Team/ablation/transfer status;
- SHA-256;
- private Hugging Face repo/object/revision pointer when non-sensitive;
- rollback pointer.

Hugging Face PRIVATE is the artifact plane:
- generated checkpoints;
- adapters/LoRA;
- derived weights;
- private validated datasets where authorized;
- associated private model memory.

## Automatic path
AGORA TASK
→ training worker
→ local/ephemeral artifact
→ provenance + license gate
→ benchmark
→ audit + Red Team
→ ablation + transfer gate
→ hash
→ upload to HF PRIVATE
→ authenticated read-back
→ verify digest
→ register F74 opaque artifact pointer
→ index F66
→ AGORA result
→ GitHub commit of metadata only.

If any gate fails: HOLD/QUARANTINE; do not promote artifact.

## Agent rule
Task agents generate/test artifacts. They do not decide publication or privilege.
The GitHub Actions workflow performs the authorized persistence automatically using repository secrets.
No token is exposed to agents, logs, GitHub files, F66 or F74.

## AFAH final lineage
AFAH-derived model artifacts remain PRIVATE by default.
AFAH-G(n+1) requires measured improvement over AFAH-G(n) under cold benchmark, audit, Red Team, ablation and transfer.
Publication requires explicit AFAH authorization.

## Storage invariant
GITHUB = code + metadata + hashes + opaque pointers.
HF PRIVATE = neural artifacts + private memories.
