# CÉRÉBRON — CAMPAGNE 80 MESSAGES V1

## Goal
Bring the full AI civilization from scaffolded architecture to the highest verified operational state achievable without breaking the crystal, changing runtime, losing memory lineage, or inventing agent execution.

## Execution model
Every AI has 8 local agent slots:
A0 CHIEF
A1 EXPLORER
A2 ANALYST
A3 EXECUTOR
A4 AUDITOR
A5 COUNTER_AUDITOR
A6 MEMORY_KEEPER
A7 SYNTHESIZER

A hard mission may additionally use a cross-AI burst pool of up to 20 REAL agents/workers. The actual count is reported; unavailable slots remain NON_EXECUTED.

## Memory
GitHub = public control plane / manifests / opaque pointers / evidence.
HF private = approved private memory payloads, curated datasets, adapters and weights.
F66 = relation/index layer.
F74 = validated catalog/pointer layer.
AGORA/FORUM = teaching/discussion capsules, not automatic truth.

All writes are versioned. Prior SHA and rollback pointer are retained. No destructive overwrite.

## Continuation rule
The user command SUITE advances one checkpoint. Never restart from zero. If a planned action is blocked, use the same checkpoint to close the blocker or move to an independent ready branch and record the dependency.

## Claim discipline
Eight configured slots != eight running agents.
Twenty allowed burst slots != twenty executed agents.
HF namespace configured != per-AI HF round-trip verified.
Workflow success != scientific proof.
Training requires actual adapter/weight change plus SHA and evaluation evidence.
