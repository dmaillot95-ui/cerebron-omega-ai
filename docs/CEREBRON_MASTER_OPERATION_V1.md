# CÉRÉBRON ΑΩ — FICHE MAÎTRE DE FONCTIONNEMENT

Version: post-F113 / registre 113 fermes
Status: architecture opérationnelle partielle; chaque capacité reste limitée par son niveau de preuve.

## 1. Principe
CÉRÉBRON est l'orchestrateur. Il route un problème vers le minimum utile d'IA, fermes, mémoires, recherches, simulations et audits. Α explore; Ω vérifie et ferme; SPIRAL Ω conserve la continuité vérifiée.

Règles: REALITY > COHERENCE; EVIDENCE > CONFIDENCE; CLAIM <= EVIDENCE; VERIFY BEFORE COMMIT; ABLATION BEFORE ADDITION; TRANSFER BEFORE GENERALITY; CALCULATION != PROOF; SIMULATION != TEST; WORKFLOW SUCCESS != SCIENTIFIC SUCCESS; CONSENSUS != TRUTH; MEMORY != LEARNING.

## 3. Boucle AÉLYS–ELYRA
Humain/mission -> AÉLYS -> F112 -> décision/action -> ELYRA/F113 -> monde simulé -> capteurs simulés/conséquences -> F112 -> audit/mémoire -> action suivante.
F111 fournit l'incarnation tête/visage; F113 fournit le corps complet. Une compétence de simulation ne devient jamais automatiquement une compétence robot physique.

## 5. Mondes simulés
F101-F110 forment SPACE WORLD: environnement -> construction -> villes Lune/Mars -> industrie -> énergie -> robots -> ISRU -> logistique -> civilisation/fusion. Les échanges utilisent états versionnés, cycle_id, seed, hashes, provenance, inconnues et contradictions. Les canaries protocole/dataflow déjà réussis ne constituent pas une calibration physique.

## 6. Recherche et fermes
Les fermes ne sont pas comptées comme preuves indépendantes si elles partagent modèle, données ou raisonnement. CÉRÉBRON choisit une coalition utile; il ne doit pas appeler 113 fermes sans nécessité. F08 sert à la recherche Web spécialisée mais sa collecte doit être liée au fingerprint de mission pour empêcher la réutilisation de sources périmées.

## 7. Mémoire et apprentissage
Flux: résultat -> quarantaine -> validation -> mémoire vectorielle et/ou candidat paramétrique -> dataset versionné -> entraînement réel -> poids/adaptateur -> benchmark froid -> transfert -> ablation -> régression -> F72/AFAH -> promotion ou rollback.
Stockage != apprentissage. Prompt != entraînement. Aucun nouvel apprentissage neuronal n'est revendiqué sans poids/adaptateur et benchmark correspondant.

## 8. Simulation Ω
Maturité: S0 REGISTERED; S1 REPOSITORY_PRESENT; S2 WORKFLOW_PRESENT; S3 WORKFLOW_EXECUTES; S4 REAL_ENGINE/MODEL_EXECUTES; S5 ARTIFACT+SHA; S6 REFERENCE_TEST; S7 REPRODUCED; S8 CALIBRATED; S9 F72/AFAH_VALIDATED.
Un simulateur physique exige S8 avant revendication de fidélité physique.

## 9. Evidence Ω
Résultat -> hash/provenance -> déduplication -> graphe de dépendance -> reproduction -> méthode alternative -> Red Team -> audit -> contre-audit -> regression guard -> F72 -> AFAH -> VALIDATED/RED/OPEN/REJECT.

## 10. Ordonnancement
Séparer LEARNING et SPACE/SIMULATION. Les calculs déterministes tournent sans IA lorsque possible. L'IA est déclenchée sur événement: contradiction, invariant cassé, nouveauté, plateau, récupération de panne, inconnue importante ou candidat GOLD. Backpressure, idempotence et quota guard avant cadence récurrente.

## 11. Chaîne cible complète
PROBLEM -> CÉRÉBRON ROUTER -> coalition minimale -> Α exploration -> calcul/recherche/simulation -> Ω vérification -> Red Team -> contre-audit -> F72 -> AFAH -> réponse -> mémoire validée -> éventuel apprentissage -> benchmark froid -> promotion/rollback -> checkpoint.

## 12. Frontières de réalité
113 entrées de registre ne signifient pas 113 IA neuronales indépendantes. Une ferme scaffoldée n'est pas une capacité scientifique validée. Une simulation réussie n'est pas un test physique. AÉLYS/ELYRA sont une architecture d'agent humanoïde et d'incarnation numérique; aucune conscience n'est revendiquée. Le transfert vers matériel réel exige des essais physiques séparés.
