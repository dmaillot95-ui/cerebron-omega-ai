# CÉRÉBRON — GREEK HYPERFUNNEL CAMPAIGN V1

## Objective
Use 24 complementary Greek AIs as a wide problem-solving funnel while keeping the final synthesis compact and evidence-bounded.

This is an execution architecture, not a claim that 24 names equal 24 independent trained models. A role counts as executed only when a real model/workflow/log/artifact exists.

## Full campaign size
24 Greek roles × 10 passes = 240 raw role-passes.

Compression:
240 raw passes -> 24 local capsules -> 6 phase capsules -> 3 independent meta-syntheses -> 1 final verified synthesis.

The final answer size does not scale with the raw search width. More work is compressed into the same final decision surface.

## Per-role 10-pass cycle
1. Scope from the role.
2. Independent first pass.
3. PI-SEARCH or role-specific expansion.
4. Alternative branch.
5. Quantitative/formal check.
6. Countercase/failure search.
7. Dependency cross-check.
8. Transfer/holdout.
9. Self-audit and limitations.
10. Local synthesis capsule.

## Phase order
P0 CONTRACT: BETA.

P1 OPEN: ALPHA, THETA, PI, PSI in parallel when real execution exists.

P2 STRUCTURE: GAMMA, IOTA, KAPPA, LAMBDA in parallel.

P3 MODEL: DELTA, ETA, PHI, NU in parallel.

P4 STRESS: EPSILON, OMICRON, MU, RHO in parallel.

P5 OPTIMIZE/TRANSFER: ZETA, XI, UPSILON, TAU in parallel.

P6 AGGREGATE/CLOSE: SIGMA, CHI, OMEGA.

Then ELYSIUM general verification -> AFAH promotion boundary -> SPIRALION memory.

## Concurrency
Parallelism is allowed only for branches whose dependencies are satisfied. No unfinished model is simulated while another model runs. If a worker is unavailable, its slot is NON_EXECUTED and the campaign continues with available branches.

## Hyperproductivity rule
Do not wait idly for one branch when other independent branches can execute. Use independent ready work to fill the same message/cycle budget, then merge only after receipts exist.

## Evidence rules
REALITY > COHERENCE
EVIDENCE > CONFIDENCE
CLAIM <= EVIDENCE
CONSENSUS != TRUTH
SHARED BASE != INDEPENDENT EVIDENCE
PI IS NOT AN ORACLE
M6 NEVER IN TRAIN
RUNTIME FREEZE

## Conversation campaign
The user command SUITE advances to the next campaign checkpoint. A campaign may exceed 100 user-visible checkpoints. The model must preserve the exact checkpoint, completed passes, unresolved branches, evidence receipts and next dependency rather than restarting.
