# CÉRÉBRON OPEN TOOL FABRIC V1

Purpose: equip CÉRÉBRON with external open/open-weight engineering and media tools without confusing installation with scientific validation.

## Promotion chain
DISCOVERED -> LICENSE_CHECKED -> BENCHMARKED -> INTEGRATED -> VALIDATED

No stage may be skipped.

## Routing
- ASTRION: Trick, JEOD, CML, GMAT, JSBSim and future astrodynamics/mission tools.
- METRION: SU2, OpenFOAM, Code_Aster, FreeCAD, ParaView, OpenMDAO and engineering verification.
- SAPHEA: ROS 2, Gazebo, MuJoCo and execution specialists.
- ELYRA: Blender, ComfyUI and video/image/audio/3D generators.
- F72: independent evidence/dependency review.
- AFAH: final epistemic fusion only after F72.

## Mandatory adapter contract
Every integrated tool receives:
1. pinned upstream version/tag/commit;
2. upstream URL and license record;
3. deterministic install/build recipe where feasible;
4. machine-readable input/output adapter;
5. minimal reference benchmark;
6. artifact + SHA-256;
7. compute/time/memory measurement;
8. known limitations and shared dependencies;
9. rollback path;
10. evidence maturity.

## Scientific rule
Agreement between CÉRÉBRON and a third-party simulator is cross-model evidence, not physical proof. Shared equations, constants, datasets or libraries must be disclosed. Hardware/experimental validation remains separate.

## Cost rule
Prefer zero-cost/open tooling. No paid service is activated by this registry. Large local/open-weight models remain INACTIVE until compatible compute exists.

## First integration wave
P0: NASA Trick + JEOD + CML; SU2; OpenFOAM; Code_Aster.
P1: GMAT, JSBSim, FreeCAD, ParaView, OpenMDAO, ROS2/Gazebo/MuJoCo, Blender/ComfyUI/LTX.
P2: alternate video models and additional domain engines after benchmark/ablation.
